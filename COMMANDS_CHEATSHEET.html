1. Preparation & Local Flask Application (FA1)

# 1. Navigate to the project directory
cd "C:\Users\Yash\OneDrive\Desktop\devops project"

# 2. Activate Python virtual environment
.\.venv\Scripts\Activate.ps1

# 3. Run all 9 automated Pytest test cases
pytest -v

# 4. Start the Flask application locally
python -m app.app
Local Web URLs: App: http://localhost:5000 | Health: http://localhost:5000/healthz | Metrics: http://localhost:5000/metrics

2. Docker Containerization (FA2)

# 1. Build the Docker container image
docker build -t student-attendance:v1 .

# 2. Run the container with persistent storage
docker run -d --name student-attendance-app -p 5000:5000 -v attendance-data:/app/data student-attendance:v1

# 3. Verify container is healthy
docker ps

# 4. View container logs
docker logs student-attendance-app

# 5. Stop the standalone container (frees port 5000 for Kubernetes)
docker rm -f student-attendance-app

3. Kubernetes Deployment & Orchestration (FA2)

# 1. Verify that your Kubernetes cluster is active
kubectl get nodes

# 2. Apply all Kubernetes YAML manifests (PVC, Deployment, Service)
kubectl apply -f k8s/pvc.yaml
kubectl apply -f k8s/deployment.yaml
kubectl apply -f k8s/service.yaml

# 3. Verify Pod (1/1 Running), PVC (Bound), and Service (NodePort)
kubectl get pods,pvc,svc

# 4. Inspect live Kubernetes pod logs
kubectl logs -l app=student-attendance

# 5. Forward port 5000 to browser
kubectl port-forward svc/student-attendance-service 5000:5000

4. Monitoring with Prometheus & Grafana (FA2)

# 1. Start Prometheus & Grafana containers
docker compose -f monitoring/docker-compose.monitoring.yml up -d

# 2. Verify monitoring containers are running
docker ps --filter "name=attendance-"

# 3. Stop monitoring stack when demo finishes
docker compose -f monitoring/docker-compose.monitoring.yml down
